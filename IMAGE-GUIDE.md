# Website image folders

Images follow the website navigation: `images/home`, `images/about`, `images/process`, `images/uniforms/school-uniforms`, and `images/uniforms/corporate-uniforms`. Logos used across pages are in `images/shared/branding`.

Winter Blazer and Sports Jersey are separate categories, matching the existing website. No image files are currently used in Contact or Catalogue.

## Replace an image

Open its folder in GitHub, choose Add file → Upload files, and upload the replacement with the exact same filename and extension. Commit to main. After a successful deployment, refresh the website. This changes the image only; product names, descriptions, and new product cards require a website update.

Each folder has a README listing its filenames. Empty gallery slots use photo-01.png, photo-02.png, etc. Existing placeholders remain visible until the specified image is uploaded.
